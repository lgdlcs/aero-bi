# 🪂 Aero-Bi — Parapente & Speed Riding à Morzine-Avoriaz

Site vitrine pour [Aero-Bi](https://www.aero-bi.com/), école de parapente, speed riding et mini-voile à Morzine-Avoriaz (Portes du Soleil).

### 🔗 [Voir le site live →](https://www.aero-bi.com/)

## Features

- **Hero immersif** avec parapentes SVG colorés qui suivent le curseur + montagnes flat vector style travel poster
- **Section avis Google** — carousel infini avec les meilleurs avis (5/5, 627+ avis)
- **Baptêmes** — grille tarifaire complète (Classique, Performance, Sport, Must…)
- **Stages** — onglets Parapente / Speed Riding / Mini-voile
- **Responsive** — mobile-first, navigation hamburger

## Stack

```
HTML · CSS · JavaScript — zéro dépendance
```

## Structure

```
index.html    → Page unique (sections: hero, activités, avis, baptêmes, stages, à propos, vidéos, contact)

```
